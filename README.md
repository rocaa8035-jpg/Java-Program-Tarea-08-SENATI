# Java-Program-Tarea-08-SENATI
En este repositorio quiero que conozcan mi trabajo en esta tarea sobre "Java Program".

------------------------------
## Guía de Configuración del Proyecto
Este repositorio contiene 2 sistemas independientes que comparten y gestionan bases de datos específicas.
## 🛠️ Prerrequisitos
Para ejecutar cualquiera de los sistemas, necesitas instalar el siguiente software:

* XAMPP: Requerido para el servidor de base de datos MySQL.
* Apache NetBeans IDE: Requerido para abrir y ejecutar los proyectos Java.

------------------------------
## 📁 Estructura del Repositorio
El proyecto está organizado en las siguientes carpetas principales:

* Bases-De-Datos/: Contiene los scripts SQL de las bases de datos.
* EntregableClienteCRUD/: Código fuente Java del primer sistema.
* gestionBD/: Código fuente Java del segundo sistema.

------------------------------
## 🚀 Casos de Uso y Configuración
Identifica el sistema que deseas ejecutar y sigue las combinaciones correspondientes:
## Caso 1: Creación de Base de datos "CLICEXPRESS"

* Base de Datos: Archivo clicexpress_db.sql (dentro de Bases-De-Datos/).

## Caso 2: Primer Sistema (Cliente CRUD)

* Código Java: Carpeta EntregableClienteCRUD.
* Base de Datos: Archivo BD_script.sql (dentro de Bases-De-Datos/).

## Caso 3: Segundo Sistema (Gestión BD)

* Código Java: Carpeta gestionBD.
* Base de Datos: Archivo BD_script.sql (dentro de Bases-De-Datos/).

------------------------------
## 💻 Instrucciones de Ejecución

   1. Abre el panel de control de XAMPP.
   2. Inicia el módulo de MySQL.
   3. Importa el archivo .sql correspondiente al caso en tu gestor de base de datos (phpMyAdmin).
   4. Abre Apache NetBeans IDE.
   5. Importa la carpeta del proyecto Java asociada al caso.
   6. Ejecuta el proyecto desde el IDE.
